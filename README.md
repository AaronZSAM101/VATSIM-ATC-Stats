# VATSIM-ATC-Stats
This is a Python script made for controllers who have endorsements in other divisions or vACCs, to help with TVCP rules.

I hope this script helps you avoid reports from people who have too much free time and like to check other ATCs' stats based on VATSIM's TVCP rules.

# How to use
Enter your VATSIM CID and your online callsign's prefix into `PersonalData.py` and run `main.py`.
